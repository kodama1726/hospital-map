# 病院マップ

全国の病院を地図上に表示し、病床数とカテーテル室で行う循環器治療の実績（DPC公開データ）を病院ごとに確認できる静的サイト。

公開ページ：https://kodama1726.github.io/hospital-map/

## 使い方

```
npm install
npm run serve              # docs/ をローカル配信（http://localhost:8080）
```

`?h=<医療情報ネットID>` を付けると、その病院の詳細パネルを開いた状態で表示する。

データを作り直す場合：

```
npm run download           # 元データを raw/ に取得（約50MB、リポジトリには含めない）
npm run geocode            # 座標欠損の補完（結果は raw/geocode_cache.json にキャッシュ済み）
npm run build              # docs/data/ と確認用CSVを生成
```

GitHub Pages は main ブランチの `docs/` を公開している。

## カテーテル治療グループ

10件以上の実施（公表値あり）がある治療の組み合わせで、上から順に判定する（`build.js` の `groupOf`）。

| グループ | 条件 | 施設数 |
|---|---|---|
| 構造的心疾患（SHD）まで対応 | 経カテーテル弁治療または経皮的左心耳閉鎖術が10件以上 | 256 |
| 冠動脈＋アブレーション | PCIとアブレーションがともに10件以上 | 489 |
| 冠動脈インターベンション中心 | PCIが10件以上 | 454 |
| 不整脈・デバイス中心 | PCIは10件未満で、アブレーションまたはペースメーカー等が10件以上 | 62 |
| 大動脈・末梢血管中心 | 上記以外で、ステントグラフトまたは末梢血管内治療が10件以上 | 32 |
| 10件以上の治療なし | DPCデータはあるが、いずれも10件未満 | 4,784 |

地図の色は、色覚多様性に配慮して検証した3色を主要3グループに使い、少数の2グループは灰色で表示する（グループ名はツールチップと詳細パネルに表示）。

## クラスター分析（実績の類似度）

`scripts/cluster.js`（`npm run build` で build.js の後に実行される）。

- 対象：いずれかのカテーテル治療が10件以上ある1,293施設
- 特徴量：PCI（AMI）、PCI（狭心症）、アブレーション、ペースメーカー等、経カテーテル弁治療、左心耳閉鎖、ステントグラフト（3分類の合計）、末梢血管内治療の8指標。件数を log(1+件数) に変換してから標準化した。秘匿値（0〜9件）は4.5で補完した。
- 手法：k-means。k-means++ で初期化し、30回試行したうち最良の解を採用した。乱数シードは固定しているため、同じデータなら同じ結果になる。
- k の選択：シルエット係数は k=2 の 0.40 から k を増やすほど単調に下がった（k=7 で 0.257）。明確な群構造は弱く、規模の連続的な違いが主である。k=7 では、規模の段階に加えて構成の異なる群（待機的PCI・末梢血管中心）が分かれ、解釈しやすいことから k=7 を採用した。`node scripts/cluster.js --explore` で k=2〜9 を比較できる。
- 群の名前：各群での各治療の実施率から自動で付けている（`NAMES`）。
- 類似病院：標準化した特徴量空間でのユークリッド距離が近い5施設。

| クラスター | 施設数 |
|---|---|
| 全領域・高実績（左心耳閉鎖まで） | 93 |
| SHD・大動脈まで対応 | 137 |

## カテ室材料の月別推移（materials.html）

`scripts/materials.js` で、第11回NDBオープンデータ（令和6年度＝2024年4月〜2025年3月診療分、公費を含む）の次の2つを結合し、`docs/data/materials.json` を出力する。

- 特定保険医療材料：診療月別数量（全国、入院・外来）
- 医科診療行為：K手術・D検査の診療月別算定回数（全国、入院・外来）

NDBオープンデータには材料と手技を結びつける情報がない。そのため、材料名から次のKコード種別に振り分けた（`CATS` の正規表現）。脳血管・塞栓術・在宅などの材料は除外した。

| Kコード種別 | 手技の集計対象 | 主な材料 |
|---|---|---|
| PCI | K546〜K550-2 | 冠動脈ステント、PTCAバルーン、PTCA用ガイドワイヤー、IVUS、OCT、圧ワイヤー |
| アブレーション | K595 | アブレーションカテーテル、電極カテーテル（検査機能付加）、心腔内エコー |
| ペースメーカー・ICD等 | K597〜K599-5 | ペースメーカー、リード、ICD、CRT-D、リード抜去用 |
| 構造的心疾患 | K555-2、K556-2、K559-2、K559-3、K570-2、K574-2、K574-3、K594（左心耳・経カテーテル）、K562（経皮的動脈管閉鎖） | TAVI弁、MitraClip、左心耳閉鎖デバイス、弁拡張用カテーテル、ASD・PFO閉鎖 |
| 大動脈ステントグラフト | K561 | 大動脈用ステントグラフト、大動脈用PTAバルーン |
| 末梢血管・シャント | K616、K616-4、K616-6、K616-7 | PTAバルーン、末梢血管用ステント、血栓除去カテーテル |
| 共通 | D206（心臓カテーテル検査、比較用） | 造影カテーテル、ガイドワイヤー、シース、止血材料、一時ペーシング電極 |

注意点：

- 数量が10未満の月は秘匿されているため、0として合算している（合計は下限値）。
- 公開されているのは全国の月別値のみで、都道府県別×月別の材料データはない。
- 「手技1件あたり」は年間数量を手技の年間算定回数で割った目安である。IVUSなど複数の手技で使う材料や、PTAバルーンのように透析シャントでも使う材料は、実際の使われ方と一致しない。

## 突合結果（2026-10-27 時点のビルド）

- DPC参加病院 1,725/1,767（97.6%）、DPC準備病院 217/228、出来高算定病院 4,135/4,377。
- 一致しなかったものの多くは、医療情報ネットのオープンデータに掲載されていない病院（例：斗南病院、江別市立病院、日野市立病院）。詳細は `match_report.csv` を参照。

## 解釈上の注意

- 数値は**該当する手術を受けた退院患者数**であり、手術件数（手技数）ではない。
- **主傷病の診断群で集計**しているため、別の病名で入院した患者への治療（例：心不全入院中のPCI）は含まれない。
- 公表値の「-」は **0〜9件**（0件を含む秘匿）。サイトでは「10未満」と表示し、合計値は下限値として扱う。
- DPCデータを提出していない病院には、カテーテル治療の実績を表示しない。
- 合併・分割した病院（例：大阪警察病院と第二大阪警察病院）は、DPCで別の告示番号となっている。現状は一方のみを採用している。
- DPCデータの最新は令和6年度分（令和8年3月公表）。令和7年度分は例年3月ごろに公表されるため、公表後に `raw/` のファイルを差し替えて `build.js` を再実行する。手術分岐の番号は診療報酬改定（ツリー改定）で変わるため、そのたびに電子点数表で対応を確認する。
